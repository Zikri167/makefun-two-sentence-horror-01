# Two-Sentence Horror

A program that writes the scariest horror story it can tell in exactly two sentences. A quiet, everyday habit — a pair of slippers kept by the back door — is reframed by one small detail in the second sentence, and the first sentence reads worse on a second read. No gore, no explanation: the reader fills in the worst.

Run it with Node 22:

```sh
node main.ts
```

It writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
